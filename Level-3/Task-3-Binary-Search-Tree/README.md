# Binary Search Tree (BST) Implementation

## Project Description

This is a Java console-based Binary Search Tree (BST) implementation developed using Object-Oriented Programming concepts and recursion.

The application allows users to perform various Binary Search Tree operations such as insertion, searching, deletion, and tree traversals.

- Insert Node
- Search Node
- Delete Node
- Inorder Traversal
- Preorder Traversal
- Postorder Traversal
- Menu-Driven Interface

## BST Operations

### Insert Node

Adds a new node to the Binary Search Tree while maintaining BST properties.

### Search Node

Searches for a specific value in the tree.

### Delete Node

Removes a node from the tree while maintaining BST structure.

### Inorder Traversal

Displays nodes in sorted order.

### Preorder Traversal

Displays the root node first, followed by left and right subtrees.

### Postorder Traversal

Displays left subtree, right subtree, and then the root node.
